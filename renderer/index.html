설정(⚙) 탭에서 Vertex AI 서비스 계정 JSON 키를 등록해주세요.
키가 없으면 번역·교정 기능을 사용할 수 없습니다.

사용 방법
  1. 설정 탭에서 Vertex AI 서비스 계정 JSON 키를 등록하세요. 한 번만 하면 이후 자동으로 복원됩니다.
  2. 번역 탭에서 모드와 도착어를 선택하세요.
  3. 텍스트를 입력하고 전송 버튼을 누르세요. 단축키 Ctrl+Enter도 사용할 수 있습니다.
  4. 결과를 재번역하려면 패널 사이 ⇐ 버튼으로 결과를 입력창에 옮기세요.
번역 vs 교정
번역 텍스트를 선택한 도착어로 번역합니다. 도착어 드롭다운에서 언어를 선택할 수 있습니다.
교정 언어를 자동 감지하여 문법·철자·구두점을 교정합니다. 도착어 선택 없이 바로 사용할 수 있습니다.
기타 기능
이력번역·교정 결과를 최대 10건 자동 저장합니다. 항목을 클릭하면 입력과 결과를 함께 볼 수 있으며, 삭제한 항목은 즉시 되돌릴 수 있습니다. 앱 종료 시 초기화됩니다.
설정사용 모델, 최대 출력 토큰, 언어 목록, 번역·교정 프롬프트를 변경할 수 있습니다. JSON 키도 이 탭에서 관리합니다.
📌사이드바 하단 버튼. 클릭하면 창을 항상 위에 고정합니다. 활성 시 파란색으로 표시됩니다.
🔆사이드바 하단 버튼. 클릭하면 창 배경 투명도 슬라이더가 나타납니다. 20~100% 범위에서 조절할 수 있습니다.
